# Lingotschytl – Cyrillic Alphabet Trainer

Learn to read Cyrillic in four languages: **Russian, Kazakh, Kyrgyz and Uzbek**.
One HTML file, no build step, no backend, no account.

## Use it

Open `index.html` in any browser, or visit the GitHub Pages site once enabled:
`https://boayusuf.github.io/lingotschytl/`

## What it does

- Every letter of each alphabet (33 / 42 / 36 / 35) with its name, sound, IPA, italic form and three words with audio
- Letters grouped by difficulty: friends, false friends (В Н Р С У Х…), new shapes, language-specific extras
- Quiz with six question types: hear → letter, letter → sound, read a word, hear a word, type the letter, read a street sign
- Weak-letter drill with a 0–5 box system (progress saved per language in the browser)
- Flashcards for words, street signs and survival phrases, with slow-speed audio

Audio uses the browser's built-in speech voices (`speechSynthesis`). Russian voices are common;
Kazakh and Uzbek voices exist on Windows and Android; Kyrgyz falls back to the Russian voice.
